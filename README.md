# 🎵 Strudel Music Project

A music project created with **Strudel**, using code to compose, arrange and
perform a complete song.

## 🎧 About

This project explores algorithmic music and live coding with Strudel.

## 🛠️ Built With

- [Strudel](https://strudel.cc/)
- Strudel Mini-Notation

Each section is programmed as its own pattern and combined together using
Strudel's sequencing and arrangement features.

## 🚀 Running the Project

Open the project in the **Strudel REPL** and run the code.

Make sure the required samples/sounds are available before playing the
patterns.
