## 🎧 About

This is a music project I made using the [Strudel REPL](https://strudel.cc/).

I recreated the intro of **"Welcome to The Black Parade" by My Chemical Romance** using Strudel's pattern-based programming language. The main goal was to get the result as close to the original recording as possible.

I recreated the different parts of the intro in code and put them together into one arrangement. I also spent some time trying different instruments and effects to get closer to the original sounds.

It was very difficult to get everything exactly right since Strudel doesn't have some of the sounds and features that I would normally have in a DAW. Because of that, some parts are approximations that may sound different from the original record... :((

Furthermore adjusting the tempo of each note manually was extremely hard and was stressing me out for some hours. It is ready and sounding better than I expected it would do!

## 🚀 How to run

You can run it directly in the [Strudel REPL](https://strudel.cc/)!

Just:
1. Open the Strudel REPL.
2. Copy the code from `main.strudel`.
3. Paste it into the editor.
4. Press play.
