## 🎧 About

This is a musical project made by me (tiagotodescatto) in the Strudel REPL website, which uses the Strudel programming language to translate the code into functional music. In this project I've made a cover of the intro of "Welcome to The Black Parade", originally written by the band My Chemical Romance. My project tries to sound just like the record with the highest fidelity possible, although Strudel has lack of some crucial functionalities that made this objective harder to achieve...

## 🚀 How to run the project

Open the project in the [**Strudel REPL Website**](https://example.com), paste the code from _main.strudel_ and run it! There is no additional requirements, for I haven't used any custom sample.
